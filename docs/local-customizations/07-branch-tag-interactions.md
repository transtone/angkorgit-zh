# 07 分支与标签交互优化

状态：已实现。将分支标签、Git 标签（tag）显示、远端状态、引用浮层和快进菜单作为同一组易用性优化维护。功能登记见 [FEATURES](FEATURES.md)；严格快进的引擎约束见 [03](03-fast-forward.md)，远端状态的数据与查询约束见 [06](06-remote-ref-status.md)。本文件统一交互要求，专项文档维护各自实现细节。

## 整体目标

用户应能直接识别当前分支、本地与远端引用、标签同步状态，并从图表或侧栏完成一致的操作。后台检查和鼠标悬停不得让标签、数量或菜单跳动；提示只表达操作对象、状态与必要后果，不展示内部实现说明或检查历史。

## 分支标签显示

- 当前检出分支优先显示，只有对应分支带勾选标记，并使用实色填充；其他引用保留所在轨道颜色。
- 同一提交的同名本地分支与正常远端跟踪引用可合并，使用本地、云端图标说明属性。独立远端引用保留远端前缀，不能把不同远端混为一个来源。
- 过期远程跟踪引用独立显示为灰色、断云图标和虚线边框，提示“过期的远程跟踪分支”。右键“删除远程跟踪引用”仅删除选中的本地跟踪引用，执行前复核，不能误删本地分支或云端分支。
- 引用列空间不足时保留完整的数量入口 `+N`，名称允许截断；悬停不得扩大原标签、挤动数量或改变原行布局。

## tag 显示与远端状态

- 图表和侧栏一致区分已同步、仅本地、状态未知及与远端不一致；多远端分别判断，不以“任一远端存在”替代当前推送目标的状态。
- 主图标与默认推送目标使用同一远端选择规则。悬停使用简短摘要，例如 `v0.27.3 · origin：已同步；upstream：仅本地`，当前目标排在首位；不显示“状态图标对应……”或逐项检查时间。
- 标签菜单支持检查远端状态及选择推送远端；已同步目标不重复推送，同名对象不同不默认强制覆盖。
- 分支与 tag 的状态检查共用查询结果。重查期间保留已有显示，各远端独立更新；失败不能构造新的缺失证据，也不能让已确认的过期分支在正常与过期分组间反复切换。首次无结果及标签查询失败显示未知。

## 多引用浮层与右键菜单

- 更多引用在独立浮层中纵向排列，覆盖原标签位置；按实际矩形定位，首项左上角与原标签对齐，不用固定补偿值猜测位置。
- 浮层使用不透明的主题底色，遮住下方标签和图线；无边框、阴影、内边距或位移动画。显示时隐藏原标签绘制但保留占位，避免半透明颜色叠加；`+N` 不移动。
- 限制浮层尺寸，超出时滚动；打开时抑制原生提示，避免提示框遮住引用列表。
- 引用右键菜单标题使用来源标签轨道色，过期引用使用中性灰；当前分支不照搬实色标签上的白字。标题加粗、增加上下留白并允许完整引用名换行，下方加细分割线；菜单背景和操作项保持原色。
- 双击和右键沿用图表与侧栏对应操作。右键菜单是引用浮层操作的延续：从浮层打开菜单后保持来源浮层，鼠标移向菜单不能触发延迟关闭；菜单关闭或操作完成后释放。

## 快进菜单

- 图表与侧栏使用相同的双向快进语义：当前分支快进到所选分支，以及所选本地分支快进到当前分支。
- 只展示实际可执行的方向。同一分支、相同提交、目标领先、分叉或目标被其他工作树占用时，不提供可执行快进入口。
- 菜单异步检查绑定仓库、来源与目标；旧菜单结果不能覆盖新菜单。操作仍由后端严格校验，不能用普通合并、重置或强制移动替代。详细安全要求以 [03](03-fast-forward.md) 为准。
